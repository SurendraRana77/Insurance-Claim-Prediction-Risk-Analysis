# Model Artifacts & Evaluation Lineage

## 1. Overview
This directory stores fitted machine learning artifacts and evaluation metrics generated by the training pipeline (`ml/train.py`).

- `model_pipeline.joblib`: Serialized dictionary containing the Scikit-learn Pipeline (ColumnTransformer + Classifier), feature schemas, target mapping, and metadata.
- `metrics.json`: Detailed performance metrics, confusion matrices, ROC coordinates, Precision-Recall coordinates, candidate model comparisons, and feature importance tables.

## 2. Integrity & Security
- Model artifacts are generated locally by the application's internal training routine.
- The application will **never** deserialize arbitrary user-uploaded pickle or joblib files.
- If an artifact is missing or corrupted, the system falls back gracefully to a non-blocking empty state and allows retraining directly through the UI.

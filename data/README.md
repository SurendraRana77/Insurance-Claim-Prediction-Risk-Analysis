# Insurance Dataset Documentation

## 1. Dataset Provenance & Purpose
This dataset is the default **Benchmark Automobile Insurance Policyholder & Claim Risk Dataset** for the academic project *Insurance Claim Prediction & Risk Analysis System*.

It contains 10,000 policyholder underwriting records designed to model the likelihood of a policyholder filing an insurance claim within an annual policy period.

- **Status**: Benchmark Synthetic Demonstration Dataset (Calibrated against real-world actuarial statistics).
- **Target Variable**: `claim_occurred` (Binary: `0` = No Claim, `1` = Claim Filed).
- **Claim Frequency**: ~23.36% positive claim occurrence (reflecting natural insurance claim incidence).

## 2. Feature Dictionary

| Column | Type | Range / Values | Description |
| :--- | :--- | :--- | :--- |
| `id` | Integer | 1001 – 11000 | Unique anonymous policyholder identifier (excluded from training) |
| `age` | Integer | 18 – 75 | Driver's age in years |
| `gender` | Categorical | `male`, `female` | Driver's reported gender |
| `driving_experience` | Integer | 0 – 55 | Continuous years of licensed driving experience |
| `education` | Categorical | `high_school`, `bachelors`, `advanced` | Highest completed education level |
| `income_level` | Categorical | `low`, `middle`, `high`, `very_high` | Underwriting income bracket |
| `credit_score` | Float | 0.150 – 0.980 | Normalized financial credit score |
| `vehicle_ownership` | Binary | `1` (Owner), `0` (Financed/Leased) | Vehicle title ownership status |
| `vehicle_year` | Categorical | `before_2015`, `after_2015` | Vehicle manufacturing cohort |
| `vehicle_type` | Categorical | `sedan`, `suv`, `sports_car`, `compact` | Primary vehicle body style |
| `annual_mileage` | Integer | 3,000 – 38,000 | Estimated annual distance traveled (miles) |
| `speeding_violations`| Integer | 0 – 12 | Citations for speeding in the preceding 3-year window |
| `duis` | Integer | 0 – 4 | Driving under the influence incidents recorded |
| `past_accidents` | Integer | 0 – 8 | At-fault or reported accidents in preceding 3-year window |
| `claim_occurred` | Binary Target | `0` (No claim), `1` (Claim filed) | Supervised classification target |

---

## 3. Academic Disclaimers
1. **Separation of Probability and Severity**: This dataset models whether an incident occurred (`claim_occurred`), **not** the dollar payout amount or repair cost (claim severity).
2. **Fraud Distinction**: A positive claim (`1`) is a legitimate insurance loss event; this system does **not** identify insurance fraud.
3. **Actuarial Boundary**: Risk tiers generated by this application are illustrative decision-support boundaries and do not constitute certified actuarial rate-making.
